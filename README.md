# read-what-you-sign
Extensión (Manifest V3) que analiza T&amp;C y popups de cookies en tiempo real: resalta frases de riesgo (datos biométricos, venta de ubicación, cesión a terceros) y las traduce a español coloquial. NLP con BERT fine-tuned + inferencia local vía WebAssembly para no enviar tus datos a ningún servidor.
